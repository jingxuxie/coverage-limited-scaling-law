# Coverage-Limited Scaling Laws

This repository studies when repeated passes over a fixed sparse dataset stop helping because predictive features are absent from the unique examples.

For activation probabilities, covariance eigenvalues, and target energy

\[
p_j\asymp j^{-s},\qquad
\lambda_j\asymp j^{-a},\qquad
g_j\asymp j^{-b},
\]

the capacity, optimization, and unique-data frontiers are

\[
J_{\rm cap}=m,\qquad
J_{\rm opt}=(\eta nK)^{1/a},\qquad
J_{\rm cov}=n^{1/s}.
\]

## Main results

The proof stack establishes:

1. **Universal coverage floor.** Under a random-sign teacher prior, every learner trained on `n` unique examples incurs a Bayes—and hence minimax—lower bound
   \[
   \mathbb E\mathcal R\ge \sum_j g_j(1-p_j)^n
   \asymp n^{-(b-1)/s}.
   \]
2. **Exact one-hot replay law.** The exactly solvable benchmark obeys
   \[
   \mathcal R\asymp
   m^{-(b-1)}+(\eta nK)^{-(b-1)/a}+n^{-(b-1)/s}.
   \]
3. **Ordinary coactive replay theorem.** Example-norm-clipped, with-replacement SGD trains on every sampled multi-active row. A support certificate and Polyak averaging give
   \[
   \mathbb E\mathcal R(\bar w_T)
   \lesssim
   \frac{N^{(a-b+1)/s}}{\eta T}
   +\log^{a/s}(eN)N^{-(b-1)/s}.
   \]
   Consequently, all-data replay reaches the coverage floor after
   \[
   K_{\rm sat}=\widetilde O\!\left(\eta^{-1}n^{a/s-1}\right)
   \]
   epochs.
4. **Full frontier achievability.** A conservative progressive-data schedule with
   \[
   N_\star\asymp\min\{n,m^s,(\eta T)^{s/a}\}
   \]
   achieves the three-frontier law up to logarithms.

The theorem is deliberately scoped to clipped with-replacement replay, Polyak averaging, coordinate-addressable sparse features, and an observable support certificate. The unguarded last iterate and reshuffling follow the same exponents empirically, but their sharp finite-time proof remains open.

## Reproduce the experiments

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Quick smoke test:

```bash
make quick
```

Validate the checked-in full sweep and regenerate figures:

```bash
make check
```

Regenerate the complete laptop-scale sweep:

```bash
make full
make validate
make figures
```

The full release contains **670 training runs** and **4,285 risk checkpoints**. For the default `(s,a,b)=(1.5,2,2)` configuration:

- the fixed-exponent two-term fit has `R^2 = 0.9805` and median relative error `0.0954`;
- the measured optimization slope is `-0.4587` versus the prediction `-0.5`;
- the measured coverage slope is `-0.6548` versus the prediction `-0.6667`;
- the progressive schedule has averaged-iterate slope `-0.5016`;
- at fixed `2^18` updates, increasing unique examples from `256` to `32768` improves last-iterate risk by `12.84x`.

All checked-in tables are generated by [`experiments/multi_active_replay.py`](experiments/multi_active_replay.py), summarized in [`experiments/results/multi_active_summary.json`](experiments/results/multi_active_summary.json), and checked by [`experiments/validate_results.py`](experiments/validate_results.py).

Figure regeneration requires a LaTeX installation with the NewTX fonts; the plotting script uses embedded Type 1 fonts to satisfy AAAI PDF requirements.
